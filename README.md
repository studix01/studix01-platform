# Studix01.net - Free Online Learning Platform

A modern, responsive educational platform designed for students to learn, read lessons, practice exercises, take quizzes, and get AI-powered study assistance.

## Features

- 📚 **Lessons & Study Materials** - Browse lessons organized by subject and class level
- 📖 **Books & Notes** - Access downloadable study materials
- ✏️ **Exercises & Practice** - Practice problems for each subject
- 🧪 **Quizzes** - Take assessments and track your progress
- 📝 **Exam Revision** - Specialized materials for exam preparation
- 🤖 **AI Study Assistant** - Get help understanding difficult topics
- 📊 **Student Dashboard** - Track your learning progress
- 🔍 **Search** - Find lessons and materials quickly
- 🌓 **Dark/Light Mode** - Comfortable learning in any environment
- 📱 **Fully Responsive** - Works on phones, tablets, and computers

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla + jQuery)
- **Backend**: Node.js & Express.js
- **Template Engine**: EJS
- **Database-ready**: MongoDB/Firebase integration
- **Responsive Design**: Mobile-first approach
- **AI Integration**: Ready for OpenAI/Google API integration

## Installation

```bash
git clone https://github.com/studix01/studix01-platform.git
cd studix01-platform
npm install
npm start
```

Access the platform at `http://localhost:3000`
